
# Automatic Irrigation System (ESP32 + Arduino)

## Overview
A smart irrigation system that automates water supply based on soil moisture and temperature conditions.

## Features
- Automatic watering using sensors
- Reduces manual intervention by ~70%
- Improves water efficiency

## Technologies Used
- ESP32 / Arduino
- Embedded C / Python (depending on your code)
- Sensors (Soil moisture, Temperature)

## Working
The system monitors soil moisture levels continuously. 
When moisture drops below a threshold, the system automatically activates the water pump. 
Temperature data is also considered to optimize irrigation.

## Results
- Reduced manual watering effort significantly
- Efficient and reliable irrigation control

## Future Improvements
- IoT-based monitoring system
- Mobile app integration
